# Тестовые прошивки ВАЗ

Источник: https://chiptuner.ru/content/ser_j5/ и https://chiptuner.ru/content/ser_j72/ (скачано 2026-10-26).
Машиночитаемый каталог: `catalog.json`.

## Наблюдения по формату

- Обычный образ ПЗУ — **64 КБ** (65536 байт), и у Январь 5.1, и у Январь 7.2.
- Некоторые образы Январь 7.2 — **128 КБ** (A205DO54, A205DO57, A201CO58_): вторая половина не копия первой, разобрать отдельно.
- Файлы с заголовком `SMS-SoftJanvar72` (I201CO58, A201CO56_, A201CO57_, ASUPER11) — **сжатый формат Combiloader**, не сырой образ.
- Идентификатор ПО лежит по смещению **0x6020** (J5: `J5V05L19`; J7.2: `?203EL36`, буква производителя в 0x6020).
- Первый байт `0x02` — `LJMP` архитектуры 8051 (вектор сброса).
- `.eep` (512 Б) — дамп EEPROM; может содержать данные иммобилайзера.
- `*a.zip` у J5 — версии с **отключенным контролем ПЗУ** (КС не проверяется) — полезно для сравнения с оригиналом и поиска алгоритма КС.
- «КС» в таблице — контрольная сумма, опубликованная на сайте; для проверки будущего калькулятора КС.

## Примечания сайта

- Прошивки с префиксом «I» (Итэлма) и «A» (АВТЭЛ) у Январь 7.2 совместимы между собой.
- Прошивки J5 «АВТЭЛ» (A5…) и под канал ДД HIP9011 **несовместимы** со старыми блоками.
- Некоторые прошивки слиты с заводских авто и имеют КС, отличную от официальной (см. `config.txt` в папках).
- Если архив содержит EEPROM, нет гарантии, что он необученный (без данных иммобилайзера).
