# Доступ для агента (MCP) — этап 10

Цель: максимально автоматизировать диагностику и поиск неисправности. Агент (Claude Code или другой MCP-клиент) сам проходит проверки, сравнивает и пишет вывод, а пользователь видит каждый вызов и подтверждает в окне всё потенциально опасное.

## Как включить

- В приложении: меню «Диагностика» → «Доступ для агента (MCP, только чтение)». Настройка запоминается. Для одного запуска — ключ `--agent` (`tools/run-app.sh -- --agent`).
- Адрес: `http://127.0.0.1:8723/mcp` (Streamable HTTP, ответы JSON, без SSE и сессий).
- Claude Code в этом репозитории: `.mcp.json` (сервер `macautodiag`) и skill `.claude/skills/car-diagnostics` с порядком проверки. Другие клиенты: `claude mcp add --transport http macautodiag http://127.0.0.1:8723/mcp`.
- На вкладке «Диагностика» строка «Агент (MCP…)»: адрес, последний вызов и время, число вызовов (подсказка — последние 15).

## Устройство

- `VazCore/Agent`: `MCPServer` (JSON-RPC 2.0: `initialize`, `ping`, `tools/list`, `tools/call`; версии протокола 2025-06-18, 2025-03-26, 2024-11-05), `HTTPRequest` (разбор запроса, проверка Host/Origin), `SampleStats`, `ParkedCheck`, `MAPCharacteristic`. Тесты — `AgentTests`.
- Приложение: `AgentServer` (NWListener только на loopback 127.0.0.1), `AgentTools` (инструменты поверх `DiagnosticsModel`).
- **Агент не ставит своих запросов на K-line.** Все значения берутся из обычного опроса (`21 01` + расширенный кадр ≈5 раз в секунду, `21 03` раз в секунду, коды раз в 5 с). `sample` подписывается на кадры опроса, `take_snapshot` идёт через тот же механизм, что кнопка. Так агент не может сбить обмен с ЭБУ.

## Уровни доступа

| Уровень | Что | Состояние |
|---|---|---|
| 1. Чтение, без подтверждения | `status`, `list_ports`, `check_cable`, `connect`, `disconnect`, `read_live`, `read_dtcs`, `sample`, `check_parked`, `take_snapshot`, `start_log`, `stop_log`, `mark` | ✅ сделано 27.10.2026 |
| 2. С подтверждением в окне | сброс кодов (перед ним — снимок), ручное управление (вентилятор, лампа, обороты ХХ; только при скорости 0; возврат ЭБУ по таймеру) | ⏳ |
| 3. Недоступно агенту | запись прошивки и EEPROM, сервис `3D`, бензонасос | — |

`check_cable` шлёт 4 байта эха адаптера (ЭБУ их игнорирует) — так же, как кнопка «Проверить кабель». `connect` — быстрая инициализация и опрос, только чтение.

## Безопасность

- Слушает только 127.0.0.1; запрос с чужим `Host` или `Origin` → 403 (защита от DNS rebinding и веб-страниц). Порт 8723.
- Выключено по умолчанию.
- Агент не влияет на машину: просьбы завести мотор или нажать педаль он передаёт человеку.

## `check_parked` — проверка на стоянке

Зажигание включено, мотор заглушен, педаль отпущена; выборка 3 с. Пороги намеренно широкие: «отклонение» значит «посмотреть сюда».

| Пункт | Норма | Что значит отклонение |
|---|---|---|
| Бортсеть | 11,8–13,2 В | разряд / просадка питания ЭБУ; выше — зарядное устройство |
| ДТОЖ, ДТВ | не −40 и не 125+ | обрыв / замыкание цепи или датчик не включён в комплектации |
| ДТВ и ДТОЖ на холодном (ТОЖ < 35 °C) | разница до 12 °C | сведения: проверить один из датчиков |
| ДПДЗ | 0,3–0,8 В (или дроссель 0–2 %) | обрыв, прижатый сигнал или незакрытый дроссель |
| ДАД — давление | 85–106 кПа | характеристика в прошивке, датчик, шланг, проводка |
| ДАД — напряжение | 0,2–4,8 В | обрыв / замыкание цепи |
| ДАД — характеристика в прошивке (если передана характеристика датчика) | расхождение до 8 кПа | в прошивке наклон/смещение другого датчика |
| Текущие неисправности, аварийный режим | нет | флаги из `21 01` прямо сейчас |

Если мотор работает (обороты > 50), проверка отказывается.
