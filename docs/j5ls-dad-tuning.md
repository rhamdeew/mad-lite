## Флаги комплектации для режима ДАД+ДТВ (инструкция V43/V43A, `j5ls_v43_a.doc`)

Это **режим пользователя** (ДАД на ресивере + ДТВ, турбо или гражданский). Точный список флагов из инструкции:

**Поставить:**
- «Работать без ДМРВ (ДАД или по дросселю)»
- «Корректировать БЦН по ДТВ»
- «Датчик температуры воздуха»
- «ДТВ подключен на 44 пин вместо 51-го»
- «ДАД подключен на 40 пин вместо 7-го»

**Снять:**
- «Барометрическая коррекция дроссельного режима»
- «Рассчитывать наполнение по таблице БЦН»

> Важно: для режима «только ДАД» флаг «Рассчитывать наполнение по таблице БЦН» наоборот ставят. При ДАД **и** ДТВ этот флаг **снят** и добавлен «Корректировать БЦН по ДТВ». Сверяйте имена с битами в карте CTP до записи.

Формула автора: **P(гПа) = (Uдад + Смещение) · Наклон**. В V43 — калибровки `60D2` (наклон) и `60D4` (смещение).

|---|---|---|---|
| Волга 45.3828 | A | 20,9 | 0,332 |
| GM Нива моновпрыск | A | 18,75 (19,256) | 0,433 (0,527) |

| **GM 3BAR** | **T (2,0 бар)** | **60,9** | **0** |

Распиновка ДАД: +5 В → пин 12 ЭБУ, масса → пин 30, сигнал → пин 40. Цилиндровый объём («Датчики/ДАД/Цилиндровый объём») = объём двигателя / 4 (1499/4 ≈ 375 для стока; для 1,6 л — ≈ 400).

**Датчики 20–300 кПа (Bosch 0 281 002 996 и аналоги, 65,88 кПа/В, −0,096 В)** в таблицу не входят: это 2 бара *избытка* (305 кПа абс), по наклону выше GM 3BAR. Штатные варианты в таблице — только до 1,5 бар (MPX4250) и «GM 3BAR» (назван как 2,0).

## Выбор ДАД по диапазону (`nastr.htm`)

- Диапазоны: **250 кПа** (MPX4250AP) — избыток до 1,5 бар; **305 кПа** — до 2 бар; **405 кПа** (3 бара) — спорт.
- **Чем больше диапазон ДАД, тем хуже точность** расхода воздуха (точность ДАД ≈ 1,5 % по напряжению на всём диапазоне). 2-барный датчик в 1,3 раза точнее 3-барного. Вывод автора: не брать датчик с запасом без необходимости. У пользователя 2 бара — разумный выбор под его мотор.
- **Нельзя** ставить дизельные ДАД (Автоэлектроника/Bosch) — нет диапазона по разрежению.
- Без обратной магистрали топлива Январь-5 работает только с ДАД+ДТВ и наддувом **не выше 1,45 бар** (иначе обеднение).

## ДТВ (датчик температуры воздуха)

- По инструкции ДТВ по умолчанию — **GM/Нива** (по лицензии Delphi, тот же, что на Daewoo Espero), резистор подпора 1 кОм, на 44 ногу. Калибровка «по умолчанию GM».
- Альтернатива из `nastr.htm`: ДТВ от Hyundai Porter (калибровка BOSCH 039, открытый элемент, держит до 2 бар).
- **Если вместо штатного ДТВ стоит датчик ОЖ ВАЗ во впуске**, его характеристика другая, чем у GM/Delphi: калибровка ДТВ в прошивке должна быть подобрана под него. **Как проверить:** на остывшем моторе сравните температуру воздуха в диагностике с уличной. Сходится в пределах 1–2 °C — не трогать; сильно расходится — в прошивке чужая характеристика.
  - Правка характеристики не задевает настройку наполнения, сделанную калибровщиком на рабочих температурах: он катал машину при +15…+30 °C, где GM и ВАЗ датчики по напряжению близки; расходятся они в основном на холоде. Поэтому если температура в кадре на холоде врёт, а ездит машина нормально — это не срочно, но влияет на холодный пуск и прогрев.

## Модель температуры заряда (Tcharge) — зачем ДТВ в J5LS (`dad_model2.htm`)

Главное, чего не было в наших доках: в J5LS (с линии V43) ДТВ работает **не** через простую поправку, а через модель «температуры заряда» Delphi (как на Daewoo Espero). Это меняет роль ДТВ и смысл калибровок.

- **Температура заряда** — эмпирическая величина между температурой ОЖ и воздуха: `Tcharge = ((Tintake − Tcoolant) · Fcharge(расход) + Tcoolant) · Fcorrection(Tcharge)`.
  - `Fcharge → 0` (малый расход, ХХ): `Tcharge ≈ Tcoolant` (греется от мотора).
  - `Fcharge → 1` (большой расход): `Tcharge ≈ Tintake` (идёт свежий воздух).
  - `Fcorrection` ≈ 0,85…1,00, работает на сильном минусе.
- Влияние на цикловое наполнение: **GBC ∝ (273 + 20) / (273 + Tcharge)** — приведение к нормальным условиям.
- При этой модели **табличные поправки по температурам ОЖ и воздуха отменяются** (разгружает расчёт топливоподачи).
- Таблица `Fcharge(обороты, дроссель)` строится «Матрицей» из базового циклового наполнения по двум коэффициентам: `Kmin` (влияние ТВ на малом расходе, ≈0,25) и `Kmax` (на большом, ≈0,9).

## Расчёт циклового наполнения по давлению (`dad_model.htm`)

- Базовая формула: `Pa = Pintake · Fgbccorr(обороты, дроссель)`.
- Нелинейность давления на ХХ лечится отдельной калибровкой **«Компенсация нелинейности давления» Fpcorr(Pintake)** (шаг 0,002, диапазон 0,5…1), а не переходом на фактор нагрузки по давлению (тот признан негодным для атмо: режимные точки по давлению не стационарны за 3-4 запроса).
- Полная формула с гашением «гор» на высоких оборотах: `Pa = Pintake · [1 − [1 − Fpcorr(Pintake)] · Fpcorr2(обороты, дроссель)] · Fgbccorr(обороты, дроссель)`. Выше 5100 об/мин коррекции отключаются (разгрузка расчёта).
- Шаг «поправки циклового наполнения» в V43 — 0,004 (был 0,008).

## Режим «только ДТВ» (без ДАД) — для справки

Есть ещё режим без ДАД: `ЦНВ = БЦН(дроссель, обороты) · 32 · Kтв(ТВ)`. Фактического давления нет → есть ошибка состава при изменении атмосферного давления/высоты. На гражданских моторах и с РХХ применять нельзя. Пользователю не подходит (у него есть ДАД).

## Возможности версий J5LS (`january2019.htm`)

Сводная таблица автора (2019). Для поздних V43 отмечено: базовые возможности (2-4 цил, атмо/турбо, дроссели, репер 60-2, моментный РХХ, фазовращатели, управление наддувом, ассист КПП вверх), порт для Январь-7.2 и Микас-7, **3-6 цилиндров**, V12 (2 ЭБУ master-slave), высокая разрешающая способность таблиц VE **32×16**.
