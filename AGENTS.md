# Правила для участников и агентов

MacAutoDiag Lite — открытая версия MacAutoDiag. Репозиторий **собирается автоматически**, поэтому исправления здесь принимаются как патчи и переносятся в исходный проект, а затем приходят со следующей синхронизацией. Коммиты, сделанные прямо в этой ветке, она сотрёт.

## Код

- Swift 6, SwiftPM, macOS 14+. Модули: `VazCore` (ядро без UI — не импортировать AppKit/SwiftUI), `VazEmu` (эмулятор, всегда `-O`), `VazSerial` (последовательный порт macOS), `MacAutoDiag` (приложение, SwiftUI), `VazEmuTool` (утилита `vazemu`).
- Комментарии в коде — на английском, сообщения интерфейса — на русском.
- Тесты — Swift Testing (`@Test`, `#expect`), на прошивках из `firmware/`. Проверка: `swift build` и `swift test`.
- На macOS файловая система нечувствительна к регистру: не заводите папки, отличающиеся только регистром.

## Безопасность

Опасные для железа действия (запись в ЭБУ, вход в загрузчик) — только с явного согласия и с предупреждением о риске. Что не проверено на живом блоке, помечайте «не проверено».
